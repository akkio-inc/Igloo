Igloo {{ .Chart.AppVersion }} is installed as release "{{ .Release.Name }}" in namespace "{{ $ns }}".

On first start the igloo pods wait for PostgreSQL and the catalog, then
create the warehouse; this can take a few minutes. Watch them with:

  kubectl --namespace {{ $ns }} get pods -l app.kubernetes.io/instance={{ .Release.Name }} --watch

1. Read the password of the admin user "{{ .Values.admin.user }}":

  export PGPASSWORD="$(kubectl --namespace {{ $ns }} get secret {{ $secret }} -o jsonpath='{.data.{{ $key }}}' | base64 --decode)"

2. Connect from your machine through a port-forward:

  kubectl --namespace {{ $ns }} port-forward service/{{ $svc }} 5433:{{ .Values.service.port }}
  psql "host=127.0.0.1 port=5433 user={{ .Values.admin.user }} dbname=igloo sslmode={{ $sslmode }}"

   Inside the cluster, connect to {{ $svc }}.{{ $ns }}.svc:{{ .Values.service.port }}.
{{- if eq .Values.service.type "LoadBalancer" }}

3. The load balancer's address (it can take a minute to appear):

  kubectl --namespace {{ $ns }} get service {{ $svc }} -o jsonpath='{.status.loadBalancer.ingress[0]}'
{{- end }}

Health and Prometheus metrics: http://{{ include "igloo.metricsServiceName" . }}.{{ $ns }}.svc:8080/metrics
Check the release with: helm test {{ .Release.Name }} --namespace {{ $ns }}

WARNING: service.type is LoadBalancer but TLS is off (tls.existingSecret is
empty). Passwords and query results cross the network unencrypted. Create a
kubernetes.io/tls Secret and set tls.existingSecret.
{{- end }}

Generated passwords and keys are in Secret "{{ include "igloo.secretName" . }}". `helm uninstall` keeps
it, and the PersistentVolumeClaims, so reinstalling the release finds its data
again. To remove everything:

  kubectl --namespace {{ $ns }} delete secret {{ include "igloo.secretName" . }}
  kubectl --namespace {{ $ns }} delete pvc -l app.kubernetes.io/instance={{ .Release.Name }}
