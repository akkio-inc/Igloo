Get started

Quick start

Clone the repository, then start the single-machine stack with Docker Compose.

git clone https://github.com/akkio-inc/Igloo.git
cd Igloo
  • Read the docs
  • Every setting
  • Deploy to Kubernetes or the cloud

Requires Docker with Compose v2.20 or later.

# generates deploy/single-vm/.env with random secrets and starts the stack
make up
# SQL shell as the admin user
make psql
CREATE TABLE events (id INTEGER, kind VARCHAR, at_time TIMESTAMP);
INSERT INTO events VALUES (1, 'signup', now()), (2, 'login', now());
SELECT kind, count(*) FROM events GROUP BY kind;

Any Postgres client can connect to 127.0.0.1:5433 as user igloo with the password IGLOO_ADMIN_PASSWORD from deploy/single-vm/.env (make up generates it; Igloo refuses to create the account with a placeholder such as change-me or fewer than 16 characters):

psql "host=127.0.0.1 port=5433 user=igloo dbname=igloo"

Or open the web console at http://127.0.0.1:8443 and sign in with the same user and password, or fetch results as Arrow over Flight SQL at grpc://localhost:31337:

import adbc_driver_flightsql.dbapi as flightsql

with flightsql.connect(
    "grpc://localhost:31337",
    db_kwargs={"username": "igloo", "password": "..."},
) as conn, conn.cursor() as cur:
    cur.execute("SELECT * FROM events")
    # or fetch_arrow_table(), or polars.read_database(query, conn)
    df = cur.fetch_df()

Load the TPC-H benchmark data and run its 22 queries:

# scale factor 1: 6 million lineitem rows
make load-tpch
# runs and times all 22 TPC-H queries
make tpch

On a laptop, the scale factor 1 load takes about 20 seconds and the 22 queries take about 4 seconds in total with warm caches; their results match the official TPC-H answers.

Deploy

Runs anywhere

Igloo runs in your own cloud account or on your own hardware.

  • One machine

    Laptop, VM or on-prem server, with Docker Compose: make up
