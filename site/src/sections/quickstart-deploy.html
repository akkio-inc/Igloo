Get started

Quick start

Clone the repository, then start the single-machine stack with Docker Compose.

git clone https://github.com/akkio-inc/Igloo.git
cd Igloo
  • Read the docs
  • Every setting
  • Deploy to Kubernetes or the cloud

Requires Docker with Compose v2.20 or later.

# generates deploy/single-vm/.env with random secrets and starts the stack
make up
# SQL shell as the admin user
make psql

Then open the web console at http://127.0.0.1:8443, or connect any Postgres client to 127.0.0.1:5433, as user igloo with the password make up wrote to deploy/single-vm/.env.

Migrate

Start with the data you already have

Query your Snowflake tables where they are, join them with Igloo's, and copy them over one statement at a time.

  • Read Snowflake in place

    Only the columns and rows a query needs come back from Snowflake, and Igloo's grants and policies apply to them.

  • Copy one table at a time

    CREATE TABLE AS streams a table into Iceberg without holding it in memory. PostgreSQL and MySQL databases work the same way.

  • Keep your other engines

    Spark, Trino, Databricks and Snowflake read and write Igloo's tables through its Iceberg REST catalog.

-- read Snowflake where it is
CREATE CONNECTION wh TYPE snowflake WITH (
  account 'myorg-myaccount',
  user 'IGLOO',
  private_key_secret 'wh.p8',
  warehouse 'IGLOO_WH',
  database 'ANALYTICS');

SELECT c.region, sum(o.amount) AS revenue
FROM wh.marts.orders o
JOIN lake.crm.customers c ON c.id = o.customer_id
GROUP BY ALL;

-- when you're ready, copy it into Igloo
CREATE TABLE lake.marts.orders AS
  SELECT * FROM wh.marts.orders;
