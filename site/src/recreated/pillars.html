Why Igloo

Postgres-compatible

Clients connect over the PostgreSQL wire protocol, so psql, JDBC, psycopg, pgx, dbt, BI tools and notebooks work without an Igloo driver.

Arrow-native extracts

Arrow Flight SQL streams results to pandas, polars, Spark and BI tools as Arrow record batches, through ADBC or the Flight SQL JDBC driver, several times faster than the PostgreSQL protocol.

Open table format

Tables are Apache Iceberg in object storage (S3, GCS, Azure Data Lake Storage, or any S3-compatible store), with no proprietary storage to migrate out of. Spark, Trino and PyIceberg read and write them through Igloo's Iceberg REST catalog.

Fast on one machine, cheap to run

Queries run on an embedded DuckDB. Most analytical workloads fit on a single node; you pay for your own VMs and storage, nothing else.

Runs anywhere

Docker Compose for one machine, a Helm chart for any Kubernetes cluster, and OpenTofu modules that stand up the whole stack on AWS, Google Cloud or Azure.

Open source

Licensed under Apache 2.0. Every component uses a permissive open-source license (Apache 2.0, MIT or the PostgreSQL License), except two libraries under the LGPL 2.1 inside DuckDB's extensions.
